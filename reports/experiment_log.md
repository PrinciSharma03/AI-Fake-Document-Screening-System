# Experiment log (AI/ML, Member 1)

Dataset: 120 fictional marksheets (60 genuine, 60 manipulated), generated by src/data_processing/generate_marksheets.py
Features: blur_score, noise_level, edge_density, contrast, ocr_confidence (5 whole-image features)
Evaluation: grouped splits (an original and its forged copy always stay together)

## Version A: first baseline
Generator settings: forged patch colour BG_EDIT = (248, 248, 244), forged text 2 pt smaller

| Model | Hold-out accuracy (30 rows) | 5-fold CV accuracy | CV precision | CV recall |
|---|---|---|---|---|
| Logistic Regression | 0.733 | 0.725 | 0.765 | 0.65 |
| Random Forest | 0.467 | 0.525 | 0.526 | 0.50 |

CV confusion matrix, Logistic Regression: [[48 12] [21 39]]
CV confusion matrix, Random Forest: [[33 27] [30 30]]
Saved model: Logistic Regression (higher CV accuracy)
Note: the signal may come from artifacts in my generator (patch colour, font size), not from real forgery cues.

## Version B: artifacts removed
Generator settings: BG_EDIT = BG, forged text the same size as the original

| Model | Hold-out accuracy | 5-fold CV accuracy | CV precision | CV recall |
|---|---|---|---|---|
| Logistic Regression | 0.500 | 0.483 | 0.481 | 0.417 |
| Random Forest | 0.533 | 0.467 | 0.468 | 0.483 |

CV confusion matrices: LR [[33 27] [35 25]], RF [[27 33] [31 29]]
Conclusion: With the generator artifacts removed, both models are at chance (about 48%). The 5 whole-page features cannot detect small local edits. Version A's 72.5% came from artifacts in my forgery code.
